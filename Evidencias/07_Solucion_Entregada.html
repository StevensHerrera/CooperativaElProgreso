Cooperativa Financiera El Progreso
Versión 1.0 | 2026

1. Contenido entregado

  • Código fuente completo del proyecto CooperativaElProgreso.
  • Proyecto de pruebas CooperativaElProgreso.Tests.
  • Diagrama editable diagrama-clases.mmd.
  • Documentos PDF de diseño, código, manual, UML, mockups y modelo futuro.
  • Archivo README.md con descripción, arquitectura y ejecución.

2. Funcionalidad verificable

  • Registro, consulta, actualización y eliminación controlada de asociados.
  • Consignaciones y retiros con validaciones.
  • Comisión de manejo para retiros superiores a $1.000.000 COP.
  • Prohibición de saldos negativos.
  • Saldo calculado desde movimientos.
  • Consulta de TRM oficial y conversión a dólares.
  • Reportes administrativos.

3. Ejecución

cd CooperativaElProgreso

cd ../CooperativaElProgreso.Tests

4. Consideraciones
La versión entregada utiliza almacenamiento en memoria, por lo que no se adjunta una base de datos real ni scripts de migración. El documento de modelo de datos presenta la estructura recomendada para implementar persistencia en una siguiente versión.
La aplicación tampoco expone una API propia; consume la API pública de TRM mediante HttpClient. Los mockups incluidos representan conceptualmente los menús de consola actuales.
