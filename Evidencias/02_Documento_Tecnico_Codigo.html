3. Flujo general del sistema

  1. Program.cs crea el almacenamiento, repositorios, servicios y menús.
  2. El usuario selecciona el menú de cajero o de administración.
  3. El menú llama una interfaz de servicio.
  4. El servicio valida la entrada y aplica reglas del negocio.
  5. El repositorio consulta o agrega información al almacenamiento.
  6. El servicio retorna un OperationResult y la UI muestra el mensaje.

4. Flujo de consulta de TRM

  1. MemberService.GetBalanceInUsdAsync valida que exista el asociado.
  2. Solicita la TRM a IExchangeRateService.
  3. TrmExchangeRateService ejecuta un GET asíncrono con HttpClient.
  4. Valida HTTP, JSON, valor y fechas.
  5. Calcula el saldo en dólares y devuelve el resultado.

5. Fragmentos relevantes

Composición de dependencias

IMemberRepository memberRepository = new MemberRepository(store);
IMovementRepository movementRepository = new MovementRepository(store);
IExchangeRateService exchangeRateService = new TrmExchangeRateService();
IMemberService memberService = new MemberService(
    memberRepository, movementRepository, exchangeRateService);

El programa inyecta implementaciones concretas detrás de interfaces. Esto facilita reemplazarlas en pruebas o en una futura implementación.

Saldo derivado

public decimal GetBalance(Guid memberId) =>
    _movementRepository.GetByMemberId(memberId)
        .Sum(m => m.SignedTotal);

El saldo se calcula con el historial, en lugar de almacenarse como un campo independiente.

Regla de retiro

var fee = amount > 1_000_000m ? 8_000m : 0m;
var currentBalance = movements.Sum(m => m.SignedTotal);
var totalToDeduct = amount + fee;
if (totalToDeduct > currentBalance)
    return OperationResult<Movement>.Fail("Saldo insuficiente");

La validación se realiza antes de guardar el movimiento; por tanto, una operación rechazada no altera el historial.

Integración tolerante a fallos

using var response = await _httpClient.GetAsync(RequestUri);
var body = await response.Content.ReadAsStringAsync();
using var document = JsonDocument.Parse(body);

Las excepciones de red, cancelación, JSON y formato se convierten en un resultado fallido controlado.
