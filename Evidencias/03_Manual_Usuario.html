Cooperativa Financiera El Progreso

Guía de ejecución y operación

Aplicación de consola
Versión 1.0 | 2026

1. Descripción

Este manual explica cómo ejecutar y utilizar la aplicación de consola para gestionar asociados, registrar movimientos, consultar saldos y revisar reportes.

2. Requisitos del sistema

  • Windows, Linux o macOS.
  • SDK de .NET 10 instalado.
  • Conexión a Internet únicamente para consultar la TRM oficial.
  • Terminal o consola de comandos.
  • Permisos para ejecutar una aplicación .NET.

3. Instalación y ejecución

  1. Abrir una terminal en la carpeta del proyecto.
  2. Entrar a CooperativaElProgreso.
  3. Ejecutar dotnet run.
  4. Esperar a que aparezca el menú principal.
cd CooperativaElProgreso

4. Menú principal
===== Menú principal =====
1. Ventanilla de cajero
2. Reportes administrativos
0. Salir
Escriba el número de la opción y presione Enter.


5. Operaciones de cajero
Registrar un asociado
Seleccione la opción de gestión de asociados, ingrese documento y nombre completo y, si desea, teléfono y dirección. El sistema rechaza campos obligatorios vacíos y documentos duplicados.
Consultar un asociado
Puede buscar por número de documento o por una parte del nombre. El sistema muestra la información registrada y permite revisar sus movimientos.
Registrar una consignación
Seleccione consignación, ingrese el documento y un monto mayor que cero. La operación se agrega al historial y aumenta el saldo.
Registrar un retiro
Ingrese el documento y el monto. El sistema calcula una comisión de $8.000 COP si el retiro supera $1.000.000 COP. Si el total supera el saldo, la operación se rechaza y no se guarda.
Consultar saldo en dólares
El sistema obtiene la TRM vigente desde la API oficial y divide el saldo en pesos por ese valor. Si el servicio no está disponible, muestra un mensaje y la aplicación continúa funcionando.


6. Reportes administrativos
Desde Reportes administrativos se pueden consultar:
  • Resumen general de la cooperativa.
  • Asociados con mayor saldo.
  • Asociados inactivos.
  • Movimientos dentro de un periodo.
  • Movimientos de mayor valor.
  • Actividad por cajero.


7. Recomendaciones
  • Verifique el documento antes de registrar una operación.
  • Revise el mensaje de resultado después de cada acción.
  • Considere la comisión antes de realizar retiros superiores al límite.
  • Mantenga Internet disponible para la conversión a dólares.
  • Ejecute pruebas con dotnet test antes de entregar una versión.


8. Solución de problemas
SituaciónAcción
La TRM no está disponibleVerifique la conexión y vuelva a intentar más tarde. Las demás funciones pueden continuar.
Saldo insuficienteConsulte el saldo y reduzca el monto del retiro.
Documento duplicadoBusque el asociado existente o utilice el documento correcto.
El comando no funcionaConfirme que el SDK de .NET 10 esté instalado y que se encuentre en la carpeta correcta.
